⚡ PromptForge

The Ultimate Free AI Prompt Generator

PromptForge is a sleek, lightning-fast, and serverless web application designed to help users craft the perfect prompts for various AI models (like ChatGPT, Midjourney, GitHub Copilot, Sora, and Suno). Built entirely in a single file, it features a modern, responsive glassmorphism UI powered by Tailwind CSS.

✨ Features

Multi-Modal Support: Generate specialized prompts for Text, Image, Code, Video, and Music AI models.

Highly Customizable: Fine-tune outputs using optional parameters like AI Persona, Tone of Voice, Target Audience, Output Length, and Additional Context.

Rich Text Output: Automatically formats the generated prompt with markdown (bolding) for readability and emphasis.

One-Click Copy: Seamlessly copy the raw generated prompt directly to your clipboard.

No Backend Required: 100% static client-side architecture using vanilla JavaScript and external API integration.

Modern UI/UX: Responsive design, dark mode, glassmorphism effects, loading states, and toast notifications.

💻 Quick Start (Local Setup)

Because PromptForge is built as a single, static HTML file, running it locally is incredibly simple. You don't need Node.js, NPM, or any complicated build tools.

Clone the repository:

git clone [https://github.com/itsrkmahapatra/promptforge.git](https://github.com/itsrkmahapatra/promptforge.git)


Navigate to the directory:

cd promptforge


Run the app:
Simply double-click the index.html file to open it in your default web browser.

🛠️ Technologies Used

HTML5: Semantic structure.

Tailwind CSS (via CDN): For rapid, beautiful, and responsive styling.

Vanilla JavaScript: For DOM manipulation, state management, and handling asynchronous API calls.
