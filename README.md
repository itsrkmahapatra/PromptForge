## ✨ Key Features
- ⚡ **Template Playground**: Instant testing and customization of parameters (tone, format, depth).
- 🤖 **AI System Prompts**: Pre-engineered structures ready for ChatGPT, Claude, and Midjourney.
- 🔌 **Zero-Configuration Puter.js**: Serverless cloud syncing, prompt storage, and history out of the box.
- 🎨 **Rich Responsive UI**: Tailored with TailwindCSS for fluid utility on desktop and mobile.
- 🔒 **Privacy-First Storage**: Secure local-first processing ensures prompt security.

## 💡 Usage Example
Here is how to get started programmatically:

```javascript
// PromptForge template variables substitution example
const promptText = PromptForge.compile("Act as a {role}. Explain {concept} in detail.", {
  role: "Senior AI Engineer",
  concept: "Retrieval-Augmented Generation"
});
console.log(promptText);
```
